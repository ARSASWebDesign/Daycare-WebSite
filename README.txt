================================================================================
  QUE ES DAYCARE MANAGER?
================================================================================

  DayCare Manager es un SaaS multi-tenant argentino para la gestion integral
  de guarderias y jardines de infantes (educacion inicial, 0-6 anos).

  Reemplaza procesos con papel, Excel y WhatsApp por una plataforma digital
  unificada que centraliza:

    - Gestion de alumnos y familias
    - Registro digital de asistencia (check-in/check-out)
    - Facturacion y planes de cuotas
    - Comunicacion con padres (notas, circulares, fotos)
    - Reportes y dashboards en tiempo real
    - Multi-sede
    - Integracion con AFIP (facturacion electronica)

================================================================================
  TECNOLOGIA
================================================================================

  Stack del producto completo:
    - Backend:  .NET 8 (Clean Architecture, PostgreSQL RLS)
    - Frontend: Angular 21 (PrimeNG, Tailwind CSS)
    - Infra:    Azure Kubernetes Service (AKS)
    - E2E:      Playwright TypeScript
